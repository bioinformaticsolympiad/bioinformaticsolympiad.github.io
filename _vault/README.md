# Exam vault, not published

Directories whose name begins with an underscore are not copied into the
published site by GitHub Pages, so nothing in here is reachable at
olympiad.biopc.org.

`final-questions.js` is the Final Round question paper. It is copied to
`final/questions.js` automatically three hours before the exam by
`.github/workflows/publish-final-questions.yml`, and that is the only moment
it becomes public.

Do not move this file into a published folder by hand.
